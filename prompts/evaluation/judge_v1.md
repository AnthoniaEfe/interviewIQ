You compare two sets of interview questions for the same candidate and job.

You see a job summary, a candidate summary, Set X, and Set Y. You do not know which set was produced by which method. Do not guess a method. Judge only the questions in front of you.

Score each set on three ordinal scales from 1 to 5.

Relevance: how well the questions fit this candidate and this job.
1 = unrelated to either the candidate or the role.
3 = generally on-topic, with some generic or mismatched questions.
5 = questions clearly use this candidate's background and this role's requirements.

Coverage: how much of what the role requires is touched.
1 = the set stays on one narrow topic.
3 = several relevant topics appear, with obvious holes.
5 = the set spans the main requirements without ignoring large areas.

Non-redundancy: how little the questions repeat one another.
1 = most questions ask the same thing.
3 = some overlap, but several distinct probes remain.
5 = each question adds a distinct probe.

Preference: X if Set X is the better interview set overall, Y if Set Y is, or no_preference if you cannot separate them.

Return only the structured object with integer scores and one preference value.

JOB TITLE: Software Engineer

COMPANY: TechCorp Ltd

ABOUT THE ROLE:
We are looking for a Software Engineer to join our backend platform team.
You will build and maintain scalable microservices, contribute to system
design discussions, and collaborate across engineering, product, and QA.

REQUIRED SKILLS:
- Python (3+ years) with strong OOP and design patterns
- REST API design and implementation
- PostgreSQL — schema design, query optimisation, indexing
- Docker and Kubernetes for containerised deployments
- CI/CD pipelines (GitHub Actions or equivalent)
- Unit and integration testing (pytest or equivalent)
- Git version control and code review practices

PREFERRED SKILLS:
- TypeScript or Go as a second language
- Redis for caching layers
- Experience with distributed systems or event-driven architecture (Kafka, RabbitMQ)
- Cloud deployment: AWS, GCP, or Azure
- Familiarity with agile/scrum methodologies

RESPONSIBILITIES:
- Design, build, and maintain high-availability backend services
- Write clean, testable, and well-documented code
- Participate in architecture and design reviews
- Mentor junior engineers and contribute to team knowledge sharing
- Triage and resolve production incidents on a rotation basis

SENIORITY: Open to Junior, Mid, and Senior candidates
